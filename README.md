# FerMatter for Homebrew

```sh
brew install --cask fermatter/tap/fermatter
brew upgrade --cask fermatter/tap/fermatter
```

- Apple Silicon Mac, macOS 14 or later.
- **Unnotarized preview:** first launch may require **System Settings → Privacy & Security → Open Anyway**. [Apple's instructions](https://support.apple.com/102445).
- Install Typst or TeX tools separately: [requirements](https://fermatter.github.io/guide/requirements/).
- The cask installs the app only. It preserves projects, settings, drafts and history on replacement/removal; it keeps macOS quarantine enabled.
- [Website and guide](https://fermatter.github.io/) · [DMG and checksums](https://github.com/FerMatter/fermatter.github.io/releases).
